# Reinforcement Learning for Optimal Sensor Placement in Water Distribution Networks — Systematic Literature Review

Public working repository for the systematic literature review (SLR). This repository is separate from the empirical WDN benchmark and X-DRL software repositories.

## Scope
Review of reinforcement-learning approaches for optimal sensor placement in water distribution networks.

## Review status
- Sources searched: 7
- Records identified: 417
- Duplicates removed: 40
- Records screened: 377
- Full texts assessed: 41
- Studies included: 4
- Synthesis: narrative/comparative; no meta-analysis due to methodological heterogeneity.

## Repository structure
See the numbered folders for protocol/methods, search strategies, screening and PRISMA, included-study register, extraction synthesis, methodological appraisal, figures/supplementary files, manuscript/reporting, provenance, and pending original exports.

## Important limitations
This is a working reproducibility package, not yet a complete archival release. Original Covidence screening and extraction exports, and other provenance materials, remain outstanding. See `10_pending_author_exports/README_PENDING_EXPORTS.txt`.

Publisher-formatted full-text PDFs and full extracted article texts are intentionally excluded from this public copy because redistribution rights have not been established. See `PUBLIC_CONTENT_AND_RIGHTS_NOTE.txt`.
