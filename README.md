# Reinforcement Learning for Optimal Sensor Placement in Water Distribution Networks: A Systematic Literature Review

**Status:** Public working repository  
**Repository package:** v1.0 working package, 14 November 2026  
**Manuscript master:** EMS SLR Submission Working v17 (IEEE date filter confirmed)

## Purpose
This repository contains methods, search documentation, screening provenance, the included-study register, a manuscript-derived synthesis, and methodological appraisal materials for the systematic literature review (SLR).

## Review flow
- Records imported into Covidence: 417
- Duplicates removed: 40
- Records screened at title/abstract: 377
- Title/abstract exclusions: 336
- Full-text reports assessed: 41
- Full-text exclusions: 37 (27 wrong intervention; 6 wrong study type; 4 wrong population)
- Studies included in qualitative synthesis: 4

## Information sources
Web of Science, Google Scholar, ScienceDirect, Engineering Village, Springer Nature, IEEE Xplore, and Scopus. The publication-year filter was 2000–2026 for all seven sources.

## Important provenance distinctions
1. Covidence dates are reference-import dates, not necessarily exact database query execution dates.
2. The publication-year limit of 2000–2026 was confirmed for all seven sources.
3. ScienceDirect notes record an earlier count of 34 retrieved and 27 after document-type filtering, whereas Covidence records 56 imported across three batches. The PRISMA totals use the Covidence import history; the discrepancy is retained transparently.
4. IEEE Xplore had primary and secondary search expressions, but the Covidence import history does not identify which records came from each query.
5. The manuscript-derived study synthesis is not the original Covidence extraction export.
6. The adapted ten-criterion appraisal is descriptive, not a validated standardised instrument; no overall quality score was used.
7. Screening and extraction were conducted by one reviewer.
